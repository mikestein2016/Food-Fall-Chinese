# Original Construct 3 export (archived)

This folder holds the original Construct 3 game export that this project was
migrated away from. It is kept for reference and A/B comparison and is **not**
served — the live site is the migrated Phaser/TypeScript app at the repo root.

To run the original locally, serve this folder with any static server and open
`index.html`. The migration source lives in `app/`; see the top-level README.
